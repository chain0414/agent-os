# iOS 会话优化实施清单

方案：[已确认的优化说明](2026-10-29-ios-conversation-optimization.md)。Wayne 于 2026-10-29 授权完整实施并在结束后统一验收。

目标：自动化消息可读、长输入可折叠、键盘可收起，旋转保持响应和阅读状态。
架构：保留 SwiftUI + Textual，在会话展示模型分类，在稳定的会话状态保存交互，性能修改由基线指导。

## 约束与检查重点

- 不删原始记录、不改 API 契约、不扩大至其他客户端；不改生产最低系统版本，签名默认值遵从 Wayne 的全局公司团队要求。
- 真实会话仅作只读浏览与核查，不发送消息、不接管或处理审批；交互与性能样本另用离线合成内容。
- 已有文档改动保留；不操作其他项目的模拟器或 App，不公开发布。
- 关注分页截断、流式修订、隐藏轮次边界、中文候选、不可见选区和布局分支重建。
