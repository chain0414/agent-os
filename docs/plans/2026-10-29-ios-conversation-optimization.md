# iOS 会话阅读与输入优化方案

日期：2026-10-29 · 状态：已实现并完成本地验收；设备与手势未覆盖项见[验收记录](../performance/ios-conversation-2026-10-29.md)

需求来源：[Wayne 改动记录 W-20261029-01](../wayne-change-requests.md#w-20261029-01ios-会话阅读与输入体验)。本文描述拟实施行为，不代表已交付功能。

## 目标与现状

让 iPhone / iPad 上的会话易读、键盘能可靠收起，横竖屏切换保持响应和阅读位置。沿用 SwiftUI + Textual，首轮限定 iOS 展示与交互，不改原始会话记录。

已核查当前源码及 drawaa「梳理进展并发拆分」最近两轮记录：自动化指令和静默回执进入正文；iOS 用户消息没有长文折叠；消息区虽已配置交互式键盘收起，但缺少明确的收起入口。时间线与 Markdown 内部采用普通 `VStack`，宽度变化和布局分支切换是性能排查重点。

上述是源码与样本证据；尚未核对手机安装版本或进行真机性能采样，旋转卡顿根因与优化收益待验证。

## 展示与交互规则

### 自动化消息

Wayne 已确认：**隐藏运行指令和 `DONT_NOTIFY` 静默回执，保留有价值的结果、失败和待处理事项。**

| 内容 | 默认展示 |
| --- | --- |
| 已确认的 heartbeat 运行指令 | 隐藏整条输入 |
| 已完成、格式明确的 `DONT_NOTIFY` 回执 | 隐藏整条回执 |
| 明确的通知型回执 | 展示实际结果，去掉控制包装 |
| 错误、阻塞、审批和待处理事项 | 保留内容与必要操作 |
| 普通正文／代码中的标签、未知或损坏格式 | 原样保留 |

在展示层分类，不删除数据；会话菜单提供「显示自动化记录」。不为每条隐藏消息添加占位或计数。历史与实时消息采用同一规则，修订后重新判断。

识别结合完整包装、字段、角色和轮次关联；流式半截内容与分页缺失不能直接判为静默。保留不可见的轮次边界，防止工具组、复制／分享跨轮合并；指向隐藏项的审批仍需可操作。整页隐藏后保留继续加载历史的入口。

现有来源信息不能完全区分自动化控制包和用户粘贴的同样原文，因此保守识别并允许恢复查看。若后续需要可靠来源标识，另行规划 Connector／Server 契约；本轮不扩展系统通知和未读计数规则。

### 长输入

建议默认最多 **8 行 → 24 行 → 全文**，按实际显示行数计算；短于下一档时直接显示全文。默认提供「展开更多」，中间档提供「展开全文」「收起」，全文档提供「收起」。附件独立显示。

展开等级由稳定的会话状态保存，旋转、分屏及字体变化后重排但不重置；待发送消息转为正式回显时继承状态。展开／收起保持阅读位置，收起后消息开头可见。

保留局部选字复制，提供复制全文；不可见部分不能被选区误命中。实现需限制预览排版开销，不能仅裁剪已完整排版的长文本。首版不要求跨 App 重启保存展开等级。

### 键盘收起

采用 **交互式下拉 + 明确按钮 + 空白点击辅助**：

- 在消息区向下拖动可跟手收起，慢拖也有效，反向拖可取消；保留系统交互方式，不另设快速滑动阈值。
- 输入区附近提供「收起键盘」图标，仅软件键盘显示时出现；不替换发送／停止，支持 VoiceOver 和足够的点击区域。
- 仅点击真正空白区域收起，不覆盖链接、附件、展开按钮和文本选择；输入框内部滚动草稿、代码／表格横向滚动维持原行为。

收起仅结束编辑，不发送或清空草稿和附件；中文候选交给系统处理，不手动覆盖。统一同步当前编辑器的焦点，避免收起后因重渲染再次弹出；会话输入框与审批输入框均纳入验证。回车继续换行。

## 性能路径与验证边界

先测量，再比较自动化隐藏和有界折叠后的变化。优先稳定会话状态与阅读锚点、合并重复位置校正；按采样决定是否引入消息／分组懒加载。单条超长 Markdown 仍为瓶颈时，再单独评估块级渲染或列表容器调整。保留现有后台解析和增量处理，不预先替换渲染框架。

旋转前在底部则继续跟随，阅读历史则停留在同段附近。锚点需包含消息／段落及段内位置，不能直接复用旧宽度下的像素偏移。布局切换不丢展开状态、草稿和合理焦点；用户拖动优先，取消过期校正，避免重复加载或订阅。

验证选取代表性组合，不做无意义的全排列：

- iPhone／iPad；竖屏／横屏／iPad 分屏；静态／生成中。
- 100／300／1000 条混合记录，单条超长输入、Markdown、代码和表格；空会话及过滤后无可见消息的会话。
- 键盘展开／收起／中途取消，中文输入，审批、文本选择、历史加载和底部跟随。

使用同设备、同版本配置、同内容的 Release 构建对比；记录样本是真实会话还是合成内容。验收要求连续旋转无卡死、无错误跳转和重复加载，草稿及阅读状态正确。耗时预算在基线完成后确定，不预填未经测量的提速比例。Headless 检查不能替代实际页面与真机验证。
