# Agents Anywhere 2.2.0（未发布）

2.2 增加 iOS 阿里云实时语音输入及 Server 语音凭证接口。所有端按版本规则同步 MINOR；本轮只在 Wayne 的本机 Server 和 iPhone 安装开发版本，未公开发布。

## 接口与配套版本

- 新增 `POST /api/v2/speech/credentials`，需要当前有效用户登录；响应包含短期阿里云凭据、固定模型、允许的 WebSocket 接入点、中文/英文语言提示和音频规格。请求体为空，客户端不能指定上游地址或永久凭据，响应和错误禁止缓存。详见 [语音凭证契约](../api/speech.md)。
- iOS 2.2 的语音输入需要 Server ≥2.2。旧 Server 的 404 或未配置时的 503 显示语音暂不可用，不回退为下载 Apple 模型。其他客户端仍可使用现有会话功能。
- iOS 识别服务替换为 `qwen-audio-3.0-asr-flash-streaming`，首次无需下载本地模型，必须联网。Codex、Claude、DSH 和 Connector 仍接收用户确认后的普通文字消息。
- Android、Web、Desktop 本轮只有版本元数据同步，尚未增加阿里云语音入口。

## 配置与升级

在 Server 环境配置 `AGENT_SERVER_ASR_API_KEY`，或显式设置 `AGENT_SERVER_ASR_CONFIG_FILE` 指向私有的百炼配置 JSON，复用其中 `api_key`、`base_url`、`workspace_id`。配置变更需重启；未配置不会影响其他功能。地域、业务空间与 Key 必须匹配，永久 Key 应限制为所需 ASR 模型的权限。

临时凭据有效期为 300 秒，每用户每分钟最多签发 10 次；限流使用 Redis，无 Redis 的单进程开发模式使用有界内存。音频从手机直接发送至阿里云，Server 不接收录音；凭据和音频不写入 Timeline、附件或日志。

## 数据库

本版本无新增数据库迁移，不重置账号、会话或文件数据。

## 已知边界与验证

iOS 点按麦克风开始，麦克风与向外扩散的圆环使用固定淡蓝色表示语音处理中，不显示额外录音或取消文字；可直接点发送，结束采集并收齐最终文字后发送一次，也可先结束录音、修改文字再发送。待接管会话在用户点发送时完成接管并复核权限；录音时发送优先于停止生成，失败保留草稿。取消恢复原稿；失败或最终空结果不自动发送，空结果会撤回暂定文字。权限获准后先采集并缓存首段，准备与收尾均有超时，避免无限等待；单次最多录音 5 分钟。

真实阿里云接口已使用明确标记的合成中文语音验证，Python 与 App 实际使用的 Swift 协议代码均得到预期中文转写。合成结果不等于真实手机麦克风、噪音、蓝牙或所有网络条件下的准确率和延迟保证。安装与验证记录见 [阿里云语音输入交付](../superpowers/specs/2026-10-30-aliyun-voice-input-verification.md)。
