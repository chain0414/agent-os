# agent-os 2.3.0（未发布）

2.3 合入上游 Codex 图片记录、`/compact` 持有方路由、DSH 同步稳定性与流式附件改进。新增附件缩略图接口，所有产品端同步 MINOR 版本；独立协作扩展继续使用自身版本。

## 接口与配套版本

- Server 2.3 的上传附件引用新增 `thumbnailUrl`，并提供带鉴权的图片缩略图入口，详见[附件契约](../api/attachments.md)。旧客户端忽略新增字段，新客户端把旧 Server 缺失的字段当作无缩略图；现有原图读取与发送继续可用。
- Web、Desktop、Android 和 iOS 上传 DTO 接受可选缩略图字段，本轮未增加缩略图浏览界面。各端版本元数据同步至 2.3.0 不代表各端新增同样的界面功能。
- 使用本地文件存储时，Server 的附件上传、原图打开、Connector 内容拉取和公开分享原图路径按流处理；非本地后端保留兼容上传、原图重定向或读取路径，仍可能组装完整文件。既有 JSON 下载响应保留原有结构。缩略图生成失败不影响上传与原图访问。
- iOS 阿里云语音输入仍需要已配置语音凭证服务的 Server ≥2.2；2.3 保留既有语音接口、发送时接管和阅读交互。

## 配置与升级

源码部署需重新同步 Server 依赖以安装 Pillow。使用 DSH 同步队列改进时配套更新 Connector 与 DSH Bridge，旧客户端可继续使用现有会话和附件入口。缩略图当前面向本地文件存储，非本地后端不返回缩略图入口。

本版本没有新增数据库迁移，不引入上游 Pi/Plan 的 `v2_45`、`v2_46`，也不重置现有账号、会话和文件数据。

## 发布边界

本版本尚未公开发布，没有新的 TestFlight、App Store 或其他端安装包。本轮源码与自动检查结果以对应提交和 CI 为准；不将自动检查通过等同于真实安装、生产升级、原生 Runtime 互通或所有设备环境验收。
