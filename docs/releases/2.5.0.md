# Agents Anywhere 2.5.0

Server 新增会话首屏接口。iOS 可以先显示最近一条已同步消息，再补齐历史并恢复实时更新。

- iOS 首屏预览需搭配 Server 2.5。连接旧 Server 时仍可通过原历史接口读取会话。
- 既有客户端可继续使用原接口。Connector 和其他客户端无需同步安装。
- 此功能没有新增数据库迁移。部署仍按标准流程核对数据库版本。

## DevKit 账号接入

- Server 可接入 DevKit Project Auth。新端点用于显式绑定现有用户及兑换已绑定身份的 Agent OS 会话。升级需执行迁移 `v2_45`。配置和回退方法见[接入文档](../api/devkit-auth.md)。
- Web 2.5 提供邮箱注册、验证、绑定和登录。iOS 2.5 提供绑定后的邮箱登录。两端需要启用接入的 Server 2.5。旧客户端继续使用原有入口。
- 开启接入前应在独立实例验证飞书和 DevKit 邮箱登录返回同一个业务用户 ID，并核对设备和历史会话。
