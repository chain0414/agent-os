# Agent OS 2.6.0

Web 用户可将现有 Agent OS 账号绑定到 DevKit Project Auth。同一个 DevKit 账号可使用已验证的邮箱和已绑定的飞书身份登录。Agent OS 沿用原有用户 ID、角色、设备和会话。

- Server 2.6 增加账号绑定和登录接口。上线前应用数据库迁移 `v2_45`，并按[接入文档](../api/devkit-auth.md)核对项目、认证域、浏览器来源及回调。
- Web 2.6 支持邮箱注册、验证、绑定和登录。包含 DevKit SDK 的 Web 构建可在项目启用飞书后显示飞书入口。iOS 2.6 支持已绑定账号的 DevKit 邮箱登录。旧版客户端可继续使用原有入口。
- DevKit 暂停账号会阻止新的 DevKit 登录。既有 Agent OS 会话和原生登录仍按 Agent OS 自身的账号策略处理。
