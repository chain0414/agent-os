# Agent OS 2.7.0

DevKit 托管模式由 DevKit 处理邮箱、飞书登录及用户管理。迁移时将 DevKit 用户对应到原 Agent OS 业务用户 ID，保留原有角色、设备和会话。

- Server 2.7 在 `GET /api/v2/auth/config` 返回 `devkit.managedOnly`。使用已有数据库迁移 `v2_45`，按[接入文档](../api/devkit-auth.md)配置并核对身份归属。
- 建议配套 Web 2.7 和 iOS 2.7。Web 需构建 DevKit SDK 才能显示飞书登录。iOS 2.6 可通过已有的「使用 DevKit 登录」入口登录邮箱，原生飞书入口复用 Web 授权。
- Agent OS 已签发的应用会话和原生刷新凭据继续遵循应用原有有效期。DevKit 停用用户会阻止新的 DevKit 登录。
