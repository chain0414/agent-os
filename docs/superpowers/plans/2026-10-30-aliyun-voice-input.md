# 阿里云实时语音输入接入计划

用户已确认：复用已有本地百炼配置，替换 Apple 识别、中文和英文混说、首用不下载模型，保留文字确认发送，完成后安装 iPhone。

## 方案与边界

- 契约先行：`docs/api/speech.md` 定义 Server 凭证接口。新增 API 按项目规则将所有端版本同步到 2.2.0，不公开发布。
- Server 读取永久 Key，当前账号换取短期凭证；iPhone 直连百炼 WebSocket。无永久秘密进入源码、App、参数或输出。
- iOS 复用录音与草稿保护，按句子 ID 管理修订；明确 `language_hints=[zh,en]`，不跟随键盘。
- 目标 iPhone 已连接本机 Web 5174→Server 8000；只更新该本机开发服务，保留数据库与账号，不操作远程生产。
