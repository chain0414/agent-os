# iOS 语音输入

Wayne 已确认先实现 iPhone：点按麦克风开始、再次点按结束，转写进入文字草稿，用户确认后手动发送。取消保留开始前的文字和附件。语音入口同时覆盖新会话与已有会话。

采用 Apple SpeechAnalyzer，优先 SpeechTranscriber，设备或语言不支持时尝试设备端 DictationTranscriber。只申请麦克风权限，不上传或保存原始音频，不接第三方 API，不改变 Server、Connector、Codex 或 DSH 协议。语言跟随当前键盘（无法取得时使用系统首选语言），不悄悄改用另一种语言。首次需要系统语音模型时显示下载状态并允许取消；无可用模型、权限拒绝与音频中断提供简短的恢复提示。

## 方案取舍

- 系统键盘听写：保持可用，但入口取决于键盘，无法提供一致的应用内操作。
- Apple 设备端识别（本轮选择）：原生入口、无 API Key；受设备、语言与模型安装状态限制。
- 云端 ASR：跨设备行为更可控，但增加音频上传、服务配置与费用，本轮不引入。

## 行为约束

录音与收尾期间禁止发送和编辑，保留独立的结束与取消操作；识别结束后恢复编辑且从不自动发送。转写按音频时间范围替换暂定文字，避免中间结果重复。取消或异步回调不能覆盖其他会话、已失效草稿或用户后续修改。离开页面、切换会话、进入后台与录音中断时停止采集；保留已识别文字供确认。开始录音前不能破坏中文输入法未确认的候选文字。

## 验证边界

用假识别器验证草稿和异步生命周期，用合成输入验证 UI 的默认、录音、收尾、错误及窄屏状态，执行 SwiftPM 测试、本地化检查与 unsigned iOS 构建。模拟器或合成案例不代表真实麦克风、模型下载、中文准确率或离线能力已验证；这部分需要真机。
