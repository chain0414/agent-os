# 阿里云语音输入交付记录（2026-10-30）

## 固定淡蓝色与一键发送复核（构建 26）

Wayne 再次要求麦克风和呼吸圈都呈淡蓝色，录音中发送必须可点，点击后结束采集、收齐最后文字再发送。此前真实页面未接管，发送能力被只读门卫禁用；另有 Agent 运行中总显示停止生成的分支。现将麦克风、浅底与圆环固定为同一 `#66B3FF`，不继承页面 tint；录音时发送优先于停止生成。只有阻碍为未接管且最新能力仍支持、可用时，输入后的发送入口可操作；用户点发送后按需接管，重新核验权限再投递。离线、阻塞事项、其他权限拒绝和状态不明确仍保稿，不绕过 Server 能力，也不会后台自动接管或发送。

在同一 iPhone 13 Pro Max 上安装独立公司签名测试 App，直接编译真实 Composer、布局、原生编辑器和语音草稿模型，以合成 ASR 事件模拟录音；没有录制用户音频、调用凭证接口、接管或投递真实会话。两项 XCUITest 均通过：父页面故意使用红色 tint 时，真实截图中麦克风主色为 RGB `(102,179,255)`，外侧圆环亦通过蓝色像素检查；录音时实际 Send 启用，点击后最终文字门闩未放行前计数 0，放行后原生编辑器读取完整修订文字且只回调 1 次。Agent 运行场景同样发送 1 次，停止生成回调 0 次。已查看实际截图。测试中「交付合成最终转写」按钮仅在隔离测试 App，未进入正式产品。

完整核心回归 376 项通过，覆盖按需接管后的最新权限复核、接管失败/不确定、读取失败、并发提交、改稿和任务取消；也修复了命令目录等待期间权限变更仍执行，以及目录加载中/失败时误把命令当普通消息的竞态，两者均观察到回归先红后绿。离页或换草稿会取消输入框提交任务。950 个语言条目、819 个提取键、42 项编译资源检查和 4 项共享文案检查通过；独立审查发现的两处竞态已补回归修复。最终签名构建核对源码摘要未在构建期间变化，证书与设备描述文件有效，永久 Key 不在 App 中。

安装曾遇到 Mac 开发连接超时，设备虽可枚举但安装和查询无响应；用户按请求解锁并重新插接 USB 后，连接恢复，最终正式 `2.2.0 (26)` 已覆盖安装、启动并读取设备安装记录确认版本。常用工作目录同步最终代码，原有未跟踪文档保留。真机合成测试完整报告、截图与 Xcode 结果在忽略目录 `ios/.build/voice-color-device-probe/`，构建源码摘要在 `ios/.build/voice-send-26-build-manifest.json`；它们证明控件和收尾发送链路，不代表本轮已重新验收真实阿里云识别质量或真实会话投递。

## 入口消失复核：统一安装来源（构建 24）

已将常用工作目录的已提交更新 `d0fe2138` 合入语音分支，保留标题收放、历史阅读、输入卡片、键盘收起与语音功能；解决输入框、语言资源、版本和更新日志冲突。整合提交为 `02cf5f2c`，常用工作目录也已快进到该提交，其原有未跟踪文档保持不变，后续从该目录打包亦包含语音。新包统一为 `2.2.0 (24)`，公司签名、目标设备描述文件和永久 Key 缺席检查通过；已覆盖安装、启动并再次查询设备确认该版本。本机 Server 与 Web 入口均仍为健康的 2.2.0，无需修改账户配置或清空数据。

整合后 358 项核心测试、948 个中英文目录条目、817 个提取键和 38 项编译资源检查通过，完整 iOS 签名构建通过。模拟器的真实 Composer 在空草稿下仍显示可操作的 `chat.composer.voice`；单独的离线编辑器检查也通过，验证中文候选词保护、回车换行、草稿保留和键盘 Router。后者渲染使用临时 ASR 与图标替身，不代表真实识别或真机手势通过。

## 后续交互更新：录音中直接发送（构建 23）

Wayne 试用后要求录音时可直接发送，并将红色停止按钮改为点亮、呼吸的麦克风。已完成：发送按钮在采集中可用，点击结束采集并等待阿里云最终转写，成功后只提交一次；仍可再次点麦克风结束、编辑后发送。取消、识别失败、空结果、离开页面或切换草稿均不会触发待发送操作。麦克风保持原图标，以蓝色和系统脉冲效果表示采集；代码在系统「减弱动态效果」开启时关闭动画，该系统设置未做人工切换验证。

本轮合成 UI 输入为「原稿：请检查登录页面，保留深色主题。」，结束时延迟 500ms 返回修订结果。通过真实 Composer 与原生编辑器发送路径，实际提交内容为「原稿：请修复登录页面的输入校验，保留深色主题并补充回归测试。」，发送次数为 1。空草稿、首个转写结果尚未到达时点发送，亦得到完整最终文字且次数为 1。识别失败、最终空结果、等待收尾时取消三种场景的发送次数均为 0；取消恢复原稿。不可发送的目标下，录音中的发送入口仍禁用。以上只使用合成 ASR 事件和本地发送计数，不录制手机音频、不向 Agent 投递。

验证包括 19 项语音状态测试、11 项新会话测试（新增用例确认录音中不能绕过最终提交保护、离线不创建会话），完整 SwiftPM 回归在新增该新会话用例前为 287 项通过；38 项编译资源检查、937 个中英文目录条目及 4 项共享文案测试通过。完整签名构建通过，独立代码审查未发现遗留阻塞问题。签名与设备描述文件检查通过，永久 Key 不在 App 产物中；已用原 Bundle ID 在「Maze-13promax」更新安装并启动 `2.2.0 (23)`，设备查询确认版本和进程。本轮不改 Server，真实手机麦克风和 Agent 消息交付仍待 Wayne 体验。

## 用户目标与实际改动

Wayne 在 iPhone 上试用 Apple 识别版后遇到首次下载模型、中文被当成英文的问题，要求改用阿里云，并复用已有本地百炼配置，装机重试。

本轮已复用本地百炼配置；永久 Key 只由 Server 读取，手机获取 300 秒临时凭据并直连阿里云。iOS 用 AVFoundation 采集单声道 PCM16，识别语言显式包含中文、英文；没有 Apple 模型下载或键盘语言选择。保留文字确认发送、取消还原、附件保护、账户/会话切换取消与后台停麦。

Server 增加已登录用户的语音凭证接口，固定模型和官方上游、限制签发频率、禁止缓存及错误响应泄密。新增接口使各端版本元数据按仓库规则同步 2.2.0；Android/Web/Desktop 本轮没有新增语音入口。

## 本机更新与安装
