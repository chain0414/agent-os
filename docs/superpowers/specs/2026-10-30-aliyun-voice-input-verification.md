# 阿里云语音输入交付记录（2026-10-30）

## 后续交互更新：录音中直接发送（构建 23）

Wayne 试用后要求录音时可直接发送，并将红色停止按钮改为点亮、呼吸的麦克风。已完成：发送按钮在采集中可用，点击结束采集并等待阿里云最终转写，成功后只提交一次；仍可再次点麦克风结束、编辑后发送。取消、识别失败、空结果、离开页面或切换草稿均不会触发待发送操作。麦克风保持原图标，以蓝色和系统脉冲效果表示采集；代码在系统「减弱动态效果」开启时关闭动画，该系统设置未做人工切换验证。

本轮合成 UI 输入为「原稿：请检查登录页面，保留深色主题。」，结束时延迟 500ms 返回修订结果。通过真实 Composer 与原生编辑器发送路径，实际提交内容为「原稿：请修复登录页面的输入校验，保留深色主题并补充回归测试。」，发送次数为 1。空草稿、首个转写结果尚未到达时点发送，亦得到完整最终文字且次数为 1。识别失败、最终空结果、等待收尾时取消三种场景的发送次数均为 0；取消恢复原稿。不可发送的目标下，录音中的发送入口仍禁用。以上只使用合成 ASR 事件和本地发送计数，不录制手机音频、不向 Agent 投递。

验证包括 19 项语音状态测试、11 项新会话测试（新增用例确认录音中不能绕过最终提交保护、离线不创建会话），完整 SwiftPM 回归在新增该新会话用例前为 287 项通过；38 项编译资源检查、937 个中英文目录条目及 4 项共享文案测试通过。完整签名构建通过，独立代码审查未发现遗留阻塞问题。签名与设备描述文件检查通过，永久 Key 不在 App 产物中；已用原 Bundle ID 在「Maze-13promax」更新安装并启动 `2.2.0 (23)`，设备查询确认版本和进程。本轮不改 Server，真实手机麦克风和 Agent 消息交付仍待 Wayne 体验。

## 用户目标与实际改动

Wayne 在 iPhone 上试用 Apple 识别版后遇到首次下载模型、中文被当成英文的问题，要求改用阿里云，并复用已有本地百炼配置，装机重试。

本轮已复用本地百炼配置；永久 Key 只由 Server 读取，手机获取 300 秒临时凭据并直连阿里云。iOS 用 AVFoundation 采集单声道 PCM16，识别语言显式包含中文、英文；没有 Apple 模型下载或键盘语言选择。保留文字确认发送、取消还原、附件保护、账户/会话切换取消与后台停麦。

Server 增加已登录用户的语音凭证接口，固定模型和官方上游、限制签发频率、禁止缓存及错误响应泄密。新增接口使各端版本元数据按仓库规则同步 2.2.0；Android/Web/Desktop 本轮没有新增语音入口。

## 真实服务测试与证据边界

输入是为测试合成的中文音频，不是真实用户麦克风录音，时长 6.64 秒：

> 请帮我检查 iOS 应用的登录页面，修复语音输入的问题，然后运行测试。

真实阿里云实时识别输出（Python 客户端与 App 相同的 Swift URLSession/协议代码均得到同一文字）：

> 请帮我检查iOS应用的登录页面，修复语音输入的问题，然后运行测试。

Python 单样本从发起 WebSocket 连接到首个非空结果为 0.66 秒；这只是本次本机网络与合成样本观测，不是手机端时延承诺，也不代表其他口音、噪音或中英术语准确率已验收。临时凭证签发亦通过真实服务验证；永久 Key 已扫描确认不在签名 App 产物中。

## 本机更新与安装

手机原来连接本机 Web 5174→Server 8000。本轮只更新该本机开发 Server，保留原有数据库连接、账号与文件目录，不执行迁移。首次切换因原 uvicorn 启动命令使用相对虚拟环境脚本而失败，受控脚本自动恢复旧服务；改为同一解释器的模块启动后，Server 2.2 健康检查通过，经原 Web 入口的凭证路由未认证时返回 401 且禁止缓存。

iOS 使用公司团队 `67JNSQB28X` 签名，版本 `2.2.0`、构建 `22`，Bundle ID 保持 `com.agentsanywhere.app`。签名有效、开发描述文件包含目标设备、App 中不存在永久百炼 Key；已在 USB 连接的「Maze-13promax」上更新安装并启动。真实录音与手动消息投递仍由 Wayne 在该机体验确认。

本机 Server 当前运行此工作区的源码；将来清理工作区前需先将服务迁回常驻代码目录。个人本机部署入口与临时复核材料保留在本地，不作为公开发布流程。
